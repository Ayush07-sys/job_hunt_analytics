# Dataset Information

This project uses six synthetic recruitment datasets from Hugging Face.

**Dataset:** [Job Postings and Applications](https://huggingface.co/datasets/mindweave/job-postings-applications)

**License:** CC BY-NC 4.0 (Attribution-NonCommercial 4.0 International).

## Required CSV Files

Download and place these six files in the project root folder, alongside `data_analysis.py`:

- `applications.csv`
- `candidates.csv`
- `companies.csv`
- `interviews.csv`
- `jobs.csv`
- `offers.csv`

## Important Notes

- The dataset contains synthetic records.
- The CSV files are not included in this GitHub repository.
- Please refer to the original dataset page for download instructions and license terms.
- The Python analysis script expects the CSV files to be in the same folder as `data_analysis.py`.
